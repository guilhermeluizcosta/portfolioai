# Perfil Profissional

## Resumo
Desenvolvedor Backend com sólida experiência no desenvolvimento de sistemas corporativos, soluções baseadas em inteligência artificial e análise de dados. Atua com Java (Micronaut, Spring Boot) e Python (Flask, Django), com vivência prática no desenvolvimento de agentes inteligentes utilizando LangChain4j, arquitetura de microsserviços, mensageria assíncrona com Kafka e computação em nuvem (AWS e Azure). Possui perfil colaborativo, participando ativamente de refinamentos técnicos, code reviews e definição de arquiteturas escaláveis.

## Objetivo profissional
Atuar como Desenvolvedor Júnior (Full Stack ou Backend), evoluindo continuamente na construção de sistemas eficientes, escaláveis e de alta qualidade técnica. Contribuir para equipes ágeis resolvendo problemas complexos através de arquiteturas modernas, automações e integração de inteligência artificial.

## Principais características
- Sólida base em desenvolvimento de software orientado a objetos, microsserviços e mensageria distribuída (Kafka).
- Experiência prática na construção de agentes inteligentes com IA generativa e RAG utilizando LangChain4j e Micronaut.
- Postura proativa e comunicativa, com experiência em liderança técnica, refinamento de requisitos e realização de code reviews.
- Facilidade de adaptação e aprendizado contínuo para atuar tanto no backend quanto no frontend (React, TypeScript).
