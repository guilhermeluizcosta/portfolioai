# Experiência: DTI Digital

**Cargo:** Estagiário de Desenvolvimento de Software
**Período:** 10/2025 - Atual
**Local:** Belo Horizonte, MG

## Sobre a empresa
Empresa de tecnologia e transformação digital focada na concepção, design e desenvolvimento de produtos digitais escaláveis para grandes corporações.

## Atuação
Desenvolvimento de software full stack com foco em soluções corporativas escaláveis, participando ativamente de decisões de arquitetura, refinamento técnico e integração entre microsserviços.

## Responsabilidades
- Desenvolvimento de aplicações full stack com Java (Micronaut) no backend e React com TypeScript no frontend.
- Participação ativa em decisões de arquitetura de software e desenho de soluções técnicas.
- Realização de code reviews e refinamentos técnicos de histórias de usuário, alinhando requisitos de negócio a padrões de engenharia.
- Estruturação e integração assíncrona entre microsserviços utilizando Apache Kafka.
- Configuração e sustentação de esteiras de integração e entrega contínua (CI/CD) no Microsoft Azure.
