# Educação: Sistemas de Informação

**Instituição:** Pontifícia Universidade Católica de Minas Gerais (PUC Minas)
**Grau:** Bacharelado  
**Período:** 01/2019 - 06/2019
**Status:** Incompleto

## Descrição
Formação superior voltada para a concepção, desenvolvimento, implementação e gestão de soluções computacionais e sistemas de software corporativos, aliando engenharia de software e visão analítica de processos e negócios.

## Principais áreas estudadas
- Engenharia de Software e Modelagem de Sistemas
- Estruturas de Dados e Algoritmos
- Arquitetura de Banco de Dados e Sistemas Distribuídos
- Redes de Computadores e Segurança da Informação
